FORMAT
------
Any format next/image handles (png, jpg, webp, avif). Each image renders inside
a fixed aspect box with object-contain, so nothing is cropped and the page never
shifts while loading — you do not need to match a ratio or a size. Full-width
screenshots at roughly 1600-2000px wide look best.
